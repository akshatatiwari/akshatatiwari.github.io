About

I'm a software engineer at Uber on the Earner Intelligence Platform, where we build AI and ML infrastructure for driver and courier use cases. Most of my work is on the Earner Agent Platform, keeping AI agents reliable and affordable once they're in production.

Before this I worked on EV charging with Uber's Sustainability Tech team, and before that I did battery research for the Department of Energy at Argonne National Laboratory.

Now building

Uber · Earner Intelligence 2026 — present

Earner Agent Platform

A shared platform for building and running AI agents across Uber's earner use cases. Teams describe an agent in a YAML config instead of writing a new service, and the platform takes care of serving and running it. It's built on LangFx, Uber's framework on top of LangChain and LangGraph.

What I built

Observability

Every agent run can be traced step by step, so when something is slow, fails, or costs more than expected, it's easy to see where. Each agent also gets dashboards and a default set of alerts that teams can tune in code.

  • Distributed tracing
  • Grafana
  • M3
  • Alerts as code

LLM evaluation

A run that finishes isn't necessarily a good run, so the platform samples production outputs and scores them with LLM judges. Teams decide whether to turn it on and how much to sample, and score monitors flag it when quality slips.

  • LLM-as-a-judge
  • Sampling
  • Score monitors

Cost guardrails

Every agent calls paid models, so each one gets a spend budget. A Go service keeps track of spending, and a check before each model call can cut an agent off once it goes over.

  • Go
  • Python
  • Circuit breaker
  • gRPC

I designed and built all three, and I'm on call for them in production. I've also worked on the platform's web console and documentation.

Mapping the global race in battery technology

The Federal Consortium for Advanced Batteries is a DOE-funded effort to support the move to electric vehicles and a more resilient grid. As part of it, I helped build a model of global battery competitiveness that uses patent and R&D data to show which countries are advancing which battery technologies. We worked with the European Patent Office and federal partners.
